 一、策略本质归类

  这是一个均值回归 + 短线日内波段 + 金字塔加仓的复合策略,本质上属于"在弱势中博反弹(buy-the-dip)"。从量化角度看,接近经典的 mean-reversion + martingale-lite 框架。

  二、优点(逻辑可取之处)
  
```txt
  ┌────────────────────────┬──────────────────────────────────────────────┐
  │          维度          │                     评价                     │
  ├────────────────────────┼──────────────────────────────────────────────┤
  │ 估值过滤(52周均线下方) │ ✅ 提供安全边际,统计上回报分布偏正           │
  ├────────────────────────┼──────────────────────────────────────────────┤
  │ 基本面过滤(经营稳定)   │ ✅ 大幅降低"价值陷阱"和退市/暴雷尾部风险     │
  ├────────────────────────┼──────────────────────────────────────────────┤
  │ 分批建仓(1/3 → 2/3)    │ ✅ 优于一次性满仓,降低择时误差               │
  ├────────────────────────┼──────────────────────────────────────────────┤
  │ 大盘趋势过滤           │ ✅ 关键加分项 — 顺势均值回归胜率显著高于逆势 │
  ├────────────────────────┼──────────────────────────────────────────────┤
  │ 明确止盈(+2%)          │ ✅ 纪律性强,避免"利润回吐"                   │
  └────────────────────────┴──────────────────────────────────────────────┘
```

  三、致命缺陷(必须修补)

  1. 没有止损 — 这是最大风险

  - "T+1/T+2 收益率 >2% 卖出" 只定义了赢的出口,没定义输的出口
  - 如果第二日继续下跌,策略默认补仓到 2/3,这是**"补仓→套牢→长期持有"**的经典陷阱
  - 风险收益结构极度不对称:赢小钱(2%),输大钱(无上限)
  - 建议补充:整体浮亏 >X%(如 -7%~-10%)或持有 N 日仍未达标(如 T+5)无条件清仓

  2. 盈亏比 vs 胜率的数学问题

  - 假设胜率 65%,平均盈利 +2%,平均亏损 -8%
  - 期望值 = 0.65×2% − 0.35×8% = −1.5%(亏损)
  - 要求胜率必须 ≥ 80% 才能盈利,这个门槛对散户极高
  - "考虑大盘趋势"能把胜率从 ~55% 推到 ~70%,但仍需配合止损才有正期望

  3. "公司前景和经营稳定"过于主观

  - 必须量化为可执行规则,例如:
    - ROE 连续 3 年 >10%
    - 资产负债率 <60%
    - 近 4 季度营收/净利润同比未连续下滑
    - 无重大诉讼/商誉减值预警
  - 否则极易事后合理化(survivorship bias)

  4. -3% 触发阈值的统计意义不足

  - A 股个股日均波动率约 2-3%,-3% 是常态而非异常
  - 改进:用 Z-score(如 -1.5σ) 或 ATR 倍数,而不是固定百分比
  - 或者结合量能(放量下跌过滤掉资金流出标的)

  5. T+1/T+2 持有期太短

  - 均值回归的统计窗口通常需要 5-20 个交易日
  - 2 日内涨 2% 的条件在弱势震荡中达成率有限,容易陷入"达不到目标→不断加仓→满仓深套"

  四、量化改进建议

  入场:
    价格 < MA200 × 1.0
    日跌幅 < -1.5σ(滚动60日)
    RSI(14) < 35
    大盘(沪深300)20日趋势 ≥ 0
    基本面四条硬指标全部通过

  仓位:
    首仓 30%,跌至 -1σ 再加 30%,最多 60%(留 40% 给止损/再平衡)

  出场:
    止盈: +3%~5%(放宽至胜率与盈亏比平衡点)
    止损: 整体仓位 -8% 或 持有 ≥10 个交易日未触发止盈

  风控:
    单标的仓位 ≤ 总资产 10%
    同时持仓数 ≤ 8 只
    大盘跌破 60 日线 → 暂停开新仓

  五、回测前必须验证的事项

  1. 样本外检验:用 2015-2020 训练,2021-2025 验证,避免过拟合
  2. 包含交易成本:印花税 + 佣金 + 滑点 ≈ 0.3%/次,2% 止盈实际只剩 1.7%
  3. 极端行情压力测试:2015 股灾、2018 单边熊、2024 年初微盘股流动性危机
  4. 统计显著性:胜率与基准(随机择时)的 t 检验

  七、一句话结论

  策略的"选股逻辑"和"趋势过滤"方向正确,但"无止损 + 短持有期 + 小止盈"形成了典型的"赢小亏大"结构,加上"补仓"机制会放大尾部风险。补上明确止损和最长持有期,把 +2% 止盈放宽到 +3-5%,将主观条件量化,这套策略才有正期望值。
