仓位设计是策略的数学骨架。前面我们讨论了"应不应该补仓"(行为问题)和"什么时候买"(信号问题),但真正决定长期复利速度的,是单笔仓位的绝对数值。

  很多策略信号是对的,但仓位错了,最终结果还是亏钱 — 这就是 Kelly 公式存在的意义。

  一、为什么仓位决定一切?(数学直觉)

  1. 几何平均 vs 算术平均的鸿沟

  经典思想实验:
  - 一个游戏,期望值正:50% 涨 80%,50% 跌 50%
  - 算术期望 = 0.5 × 80% + 0.5 × (-50%) = +15%
  - 看起来很赚?

  满仓玩 100 次:
  - 资金路径:1 × 1.8 × 0.5 × 1.8 × 0.5 × ...
  - 几何平均:(1.8 × 0.5)^(1/2) = √0.9 ≈ 0.949
  - 长期年化 = -5.1%(亏损!)
  - 算术为正,几何为负 — 这就是过度仓位的杀伤力

  改成只投 25% 资金:
  - 涨时:×(1 + 0.25 × 0.8) = ×1.2
  - 跌时:×(1 - 0.25 × 0.5) = ×0.875
  - 几何平均:√(1.2 × 0.875) ≈ 1.0247
  - 长期年化 = +2.5%(正!)

  核心结论:

  ▎ 同一个策略,仓位不同,长期回报正负号完全相反。
  ▎ Kelly 公式就是回答:仓位应该是多少,才能让几何平均最大化?

  2. 这个直觉对你的策略意味着什么

  你的策略仓位上限 2/3(67%),比上面例子的 25% 高得多。
  关键问题:你的策略期望值/方差比例,真的支持这么重的仓位吗?

  下面用 Kelly 给出答案。

  ---
  二、Kelly 公式(Kelly Criterion)

  1. 起源与本质

  John Kelly Jr.(1956) 在贝尔实验室研究通信信道时,推导出最大化对数财富增长率的最优下注比例。Edward Thorp 后来把它用到 21 点和股市,成为传奇。

  核心思想:

  ▎ 不要最大化"期望财富"(那会让你倾向 all-in),要最大化"期望对数财富"(让你在多次重复博弈下复利速度最快)。

  2. 经典二元情形(简化 Kelly)

  $$
  f^* = \frac{bp - q}{b} = \frac{p(b+1) - 1}{b}
  $$

  其中:
  - $f^*$:最优下注比例(占总资金)
  - $p$:胜率
  - $q = 1-p$:败率
  - $b$:盈亏比(赔率)

  3. 套用你的策略参数

  乐观假设(策略真的有效时):
  - 胜率 $p$ = 65%(基本面+趋势过滤后的合理估计)
  - 盈利 = +2%(扣成本后约 +1.7%)
  - 亏损 = -8%(假设有止损,无止损则更糟)
  - 盈亏比 $b$ = 1.7 / 8 = 0.2125

  代入:
  $$
  f^* = \frac{0.65 \times 0.2125 - 0.35}{0.2125} = \frac{0.138 - 0.35}{0.2125} = \frac{-0.212}{0.2125} ≈ -1.0
  $$

  Kelly 给出 -100% → 意思是你应该做空这个策略(即不做),而不是做多。

  ▎ 数学上,这个策略在当前参数下根本不该执行。

  4. 反向求解:胜率/盈亏比要多少才能支持 2/3 仓位?

  要让 $f^* = 0.667$,需要:
  $$
  0.667 = \frac{p \times b - (1-p)}{b}
  $$

  整理:
  $$
  p = \frac{0.667 b + 1}{b + 1}
  $$

```txt
  ┌─────────────────┬────────────────┬───────────────┐
  │ 假设盈亏比 $b$  │ 所需胜率 $p^*$ │  现实可达性   │
  ├─────────────────┼────────────────┼───────────────┤
  │ 0.25(+2% / -8%) │ 84.7%          │ ❌ 几乎不可能 │
  ├─────────────────┼────────────────┼───────────────┤
  │ 0.5(+3% / -6%)  │ 77.8%          │ ❌ 极难       │
  ├─────────────────┼────────────────┼───────────────┤
  │ 1.0(+5% / -5%)  │ 83.3%          │ ❌ 几乎不可能 │
  ├─────────────────┼────────────────┼───────────────┤
  │ 1.5(+6% / -4%)  │ 80.7%          │ ❌ 极难       │
  ├─────────────────┼────────────────┼───────────────┤
  │ 2.0(+8% / -4%)  │ 77.8%          │ ❌ 极难       │
  └─────────────────┴────────────────┴───────────────┘
```

  残酷结论:

  ▎ 任何参数组合下,2/3 的单笔仓位都需要近 80% 胜率来支撑。
  ▎ 这个胜率门槛世界上几乎没有任何公开策略能持续达到(Renaissance Medallion 也只有 ~70%)。

  ---
  三、为什么没人用"完整 Kelly"?

  即使你的策略真的支持 30% 的 Kelly 仓位,也不应该用满。

  1. 完整 Kelly 的"狂躁"性质

  Kelly 公式假设:
  - ✅ 胜率/赔率精确已知
  - ✅ 收益分布严格独立同分布
  - ✅ 资金可以无限分割
  - ✅ 零交易成本

  现实中:
  - 你估的胜率 65% 可能实际是 50%(过拟合 / 看错趋势)
  - 历史回测的盈亏比无法外推未来
  - A 股有交易成本、滑点、跳空

  Kelly 的著名缺陷(Thorp 自己警告):

  ▎ 如果你高估了 0.1 个 Kelly,长期增长率不会"略低于最优",而是断崖式下降。

  2. 增长率 vs 仓位的关系曲线

```txt
  增长率
    ↑
    │             ╱─╲
    │           ╱     ╲   ← 完整 Kelly(理论最优)
    │         ╱         ╲
    │       ╱             ╲___
    │     ╱                    ╲___
    │   ╱   半 Kelly                 ╲___
    │ ╱     (实务最优)                    ╲
    │                                       ╲
    ├────────────────────────────────────────╲────→ 仓位
    0    f*/2                f*           2f*
                                            ↑
                                          破产

```

  关键性质:
  - $f^/2$(半 Kelly)的增长率是 $f^$ 的 75%
  - 但波动率只有完整 Kelly 的一半
  - 超过 $2f^*$,增长率为负(必然破产)

  → 这就是为什么专业机构普遍使用 1/4 Kelly 到 1/2 Kelly(Fractional Kelly)。

  3. "Kelly 安全系数"(Practitioner Adjustment)

```txt
  ┌────────────────────────┬──────────────────────┬─────────────────────┐
  │        仓位策略        │         用谁         │        特征         │
  ├────────────────────────┼──────────────────────┼─────────────────────┤
  │ Full Kelly($f^*$)      │ 数学家、扑克手       │ 高增长 + 高波动     │
  ├────────────────────────┼──────────────────────┼─────────────────────┤
  │ Half Kelly($f^*/2$)    │ 大多数对冲基金       │ 75% 增长率,50% 波动 │
  ├────────────────────────┼──────────────────────┼─────────────────────┤
  │ Quarter Kelly($f^*/4$) │ 公募基金、家族办公室 │ 44% 增长率,25% 波动 │
  ├────────────────────────┼──────────────────────┼─────────────────────┤
  │ 0.1 Kelly              │ 保守家族办公室       │ 19% 增长率,10% 波动 │
  └────────────────────────┴──────────────────────┴─────────────────────┘
```

  对你的实务建议: 即便你的策略真有正期望值,仓位也应该是 Kelly 计算值的 1/2 ~ 1/4。

  四、连续 Kelly:更适合金融的版本

  1. 公式

  对于连续收益,Kelly 公式简化为:

  $$
  f^* = \frac{\mu - r}{\sigma^2}
  $$

  其中:
  - $\mu$:策略年化期望收益
  - $r$:无风险利率(国债 ~2%)
  - $\sigma$:策略年化波动率

  2. 套用你的策略

  假设你的策略真实(乐观)参数:
  - $\mu = 12%$/年(超额年化收益)
  - $r = 2%$
  - $\sigma = 25%$(单股策略,波动很大)

  $$
  f^* = \frac{0.12 - 0.02}{0.25^2} = \frac{0.10}{0.0625} = 1.6
  $$

  → Full Kelly 给出 160% 杠杆(不可能,A 股两融杠杆上限 1:1)

  半 Kelly: 80%
  1/4 Kelly: 40% ← 这才是合理的总仓位上限

  → 注意:这是总策略仓位(你账户中分配给该策略的总资金占比),不是单股仓位。

  3. 单股仓位的进一步分解

  如果总策略仓位 40%,同时持有 N 只股票,则单股仓位:
  $$
  w_\text{single} = \frac{f^*_\text{strategy}}{N \times \sqrt{1 + (N-1)\rho}}
  $$

  其中 $\rho$ 是个股间的平均相关系数。A 股个股间 $\rho ≈ 0.5$(板块/风格相关性高)。

```txt
  ┌──────────────┬──────────┐
  │ 同时持仓数 N │ 单股仓位 │
  ├──────────────┼──────────┤
  │ 5            │ ~12%     │
  ├──────────────┼──────────┤
  │ 10           │ ~7%      │
  ├──────────────┼──────────┤
  │ 20           │ ~4%      │
  └──────────────┴──────────┘
```

  对比你当前设计:
  - 你说"1/3 → 2/3"
  - 如果是单只股票占总资产的 2/3,那是 Kelly 计算值的 16 倍,极度危险
  - 如果是该笔交易资金的 2/3(总资产 ~10% 中的 2/3),那约等于 6.7%,接近 1/4 Kelly 的合理水平

  → "1/3 → 2/3"这个表述本身就有歧义,第一步必须先澄清:基数是什么?

  五、风险平价(Risk Parity)视角

  1. 核心思想

  Bridgewater 的 Ray Dalio 提出:不要让仓位平均,要让风险贡献平均。

  经典 60/40 组合(60% 股票 + 40% 债券)看起来"分散",实际上股票贡献了 ~90% 的风险(因为股票波动远大于债券)。

  2. 风险贡献公式

  单一资产对组合的风险贡献(MRC):

  $$
  \text{MRC}i = w_i \times \sigma_i \times \rho{i,p}
  $$

  风险平价要求:
  $$
  \text{MRC}_1 = \text{MRC}_2 = ... = \text{MRC}_N
  $$

  3. 套用到你的策略

  关键洞察: 你的"1/3 → 2/3"补仓机制,违反了风险平价原则。

  问题分析:
  - 第一笔 1/3 仓位时,单股风险敞口 = 1/3 × σ_stock
  - 加仓到 2/3 时,风险敞口翻倍
  - 而此时正是你最确信"机会大"的时刻(基本面好、跌得多)
  - 但确信感不等于胜率提高

  风险平价框架会告诉你:

  ▎ 加仓点的"主观确信"被高估,加仓后的"风险贡献"被低估。

  4. 风险平价改造版

  反直觉建议: 应该 "等风险加仓",而不是 "等资金加仓"。

  原始版本:
    入场 1 → 资金 1/3
    入场 2 → 资金 2/3(资金加倍,风险也加倍)

  风险平价版本:
    入场 1 → 资金 1/3,波动率假设 σ
    入场 2 → 此时若波动率上升到 1.5σ(下跌中波动通常放大)
            → 加仓后总风险预算应保持不变
            → 加仓金额 = 1/3 × (σ/1.5σ) = 2/9
            → 总仓位 = 1/3 + 2/9 = 5/9 ≈ 56%(而非 67%)

  实际效果: 在波动放大的下跌环境中,主动缩小加仓幅度,避免过度风险暴露。

  ---
  六、CPPI(常数比例投资组合保险)— 终极防线

  1. 概念

  Black & Jones (1987) 提出,用于保证不爆仓。

  2. 公式

  $$
  E_t = m \times (V_t - F)
  $$

  - $E_t$:风险资产配置
  - $V_t$:当前总资产
  - $F$:保底底线(地板,如初始资金的 80%)
  - $m$:风险乘数(通常 3-5)

  3. 实战意义

  翻译成你的策略:
  - 假设你账户初始 100 万
  - 设定"地板"为 85 万(最大可承受亏损 15 万)
  - 风险乘数 m = 3
  - 初始风险敞口 = 3 × (100 - 85) = 45 万 → 你最多用 45 万做这个策略

  当账户跌到 95 万:
  - 新风险敞口 = 3 × (95 - 85) = 30 万
  - → 必须主动减仓 15 万

  当账户跌到 88 万:
  - 新风险敞口 = 3 × (88 - 85) = 9 万
  - → 几乎清仓

  当账户跌到 85 万:
  - 风险敞口 = 0 → 强制清仓

  → CPPI 在数学上保证你不会跌破地板(忽略跳空缺口)。

  这与你当前策略的"补仓"机制完全相反:
  - 你的策略:亏损 → 加仓
  - CPPI:亏损 → 减仓

  ▎ 专业机构在熊市的反应是减仓,散户在熊市的反应是补仓 — 这是风险预算框架的根本差异。

  ---
  七、波动率目标(Vol Targeting)— 现代实务

  1. 思想

  不固定仓位,而是固定组合波动率(如目标 15% 年化波动)。

  $$
  w_t = \frac{\sigma_\text{target}}{\sigma_\text{realized}^t}
  $$

  2. 应用

  - 当市场波动率 = 15% → 仓位 100%
  - 当市场波动率 = 30%(危机) → 仓位降到 50%
  - 当市场波动率 = 10%(平静) → 仓位提升到 150%(若允许杠杆)

  3. 对你策略的启示

  关键改造: 把"-3% 触发"这个绝对阈值,改为:
  - -1.5σ 触发(σ 是 60 日滚动波动率)
  - 仓位也按波动率反向缩放
  - 高波动期,少买;低波动期,多买

  学术证据: Moreira & Muir (2017, Journal of Finance) 证明,vol-targeted 版本的几乎所有因子策略,Sharpe 比原始版本提升 20%-50%。

  八、综合框架:你的策略的最优仓位结构

  把上述所有原则叠加应用,得到一个完整的风险预算方案:

  第一层:总策略仓位上限(战略层)

  # Kelly 框架
  mu_strategy_estimated = 0.10      # 假设年化超额收益(乐观)
  sigma_strategy = 0.20             # 策略波动率
  kelly_full = (mu_strategy_estimated - 0.02) / sigma_strategy**2   # = 2.0
  kelly_quarter = kelly_full / 4    # = 0.5

  # CPPI 上限
  floor = 0.85 * initial_capital
  m = 3
  cppi_limit = m * (current_capital - floor) / current_capital

  # 总策略仓位 = 两者最小值
  total_strategy_weight = min(0.5, cppi_limit, 0.6)  # 硬封顶 60%

  第二层:单股仓位(战术层)

  # 同时最多 N 只股票
  N_max = 8
  rho_avg = 0.5  # A 股个股相关性
  diversification_factor = sqrt(1 + (N_max - 1) * rho_avg)

  # 单股最大仓位
  w_single_max = total_strategy_weight / (N_max * diversification_factor)
  # 假设 total = 0.5, N = 8, rho = 0.5 → w_single ≈ 3.3%

  第三层:加仓机制(执行层)

  # 风险平价加仓
  def adjusted_addon(current_vol, base_vol, base_size):
      return base_size * (base_vol / current_vol)

  # 入场 1: 1/3 of single_max ≈ 1.1% of total
  # 入场 2: 1/3 × (base_σ / current_σ),通常因下跌中 σ 放大,加仓量 < 1/3

  第四层:风控触发(防御层)

  # 三道止损
  single_position_stop = -8%       # 单股亏损 8% 强制止损
  strategy_drawdown_stop = -15%    # 策略累计回撤 15% 暂停 1 个月
  account_floor_stop = -20%        # 账户总回撤 20% 全部清仓

  # 时间止损
  time_based_stop = 10  # 持有超过 10 个交易日未达盈利目标 → 出场

  十一、终极结论

  ▎ 散户和机构在策略上的最大差距,不是信号质量,而是仓位质量。
  ▎
  ▎ 你的策略信号部分(均线、跌幅、基本面、趋势过滤)接近专业水准,但仓位部分(1/3 → 2/3 + 无风控)完全是散户思路。
  ▎
  ▎ Kelly、风险平价、CPPI、Vol Targeting 不是花哨的数学,而是专业机构和散户长期回报差异的核心来源。
  ▎
  ▎ 三句话总结:
  ▎ 1. 单股仓位 ≤ 总资产 5%(无论你多确信)
  ▎ 2. 总策略仓位 ≤ Kelly 计算值的 1/4(留余地给高估)
  ▎ 3. 加仓时减少风险,而非放大风险(等风险加仓 / vol target)
  ▎
  ▎ 当你把这套框架应用到原始策略上,你会发现:
  ▎ - "1/3 → 2/3" 的具体数字:错的;应是 1% → 2-3%(以总资产计)
  ▎ - "补仓"的方向:错的;应是涨过止盈才加仓,不是跌了才加仓
  ▎ - "无止损":致命;应有 -8% 单股止损 + -15% 策略回撤暂停
