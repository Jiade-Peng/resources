人投资者的完整工具栈推荐

  工具选择直接决定你能走多远。专业的工具能让 1 小时的工作变 10 分钟,糟糕的工具会让你卡在配环境上 3 周。下面给出经过实战验证的工具推荐,按"数据 → 研究 → 回测 → 执行 → 监控"五个层次完整覆盖。

  ▎ 核心原则: 不要追求大而全,先用免费工具跑通完整流程,再按瓶颈逐步升级。

```txt
  fast_ma = vbt.MA.run(price, 10)
  slow_ma = vbt.MA.run(price, 50)
  entries = fast_ma.ma_crossed_above(slow_ma)
  exits = fast_ma.ma_crossed_below(slow_ma)
  pf = vbt.Portfolio.from_signals(price, entries, exits)
```

  4. 重要警告

  ▎ 回测平台的"陷阱":
  ▎
  ▎ 1. 未来函数:平台没明确告诉你的"今天数据",可能包含尚未公布的财报
  ▎ 2. 滑点假设过低:默认滑点 0.05%,实盘往往 0.2-0.5%
  ▎ 3. 冲击成本:几乎所有平台都不模拟大单冲击
  ▎ 4. 手续费:很多平台默认万 2.5,但没算印花税
  ▎ 5. 撮合规则:T+1、涨跌停、停牌很多平台简化处理
  ▎
  ▎ 建议: 至少跑两个不同平台对比,结果差异 > 30% 说明有问题。

  2. 主流方案详解

  东方财富 EMQuant(推荐入门)

  - 门槛: 资产 ¥20 万
  - 价格: 免费
  - 优点:

  - 缺点:
    - 速度一般(适合中低频)
    - 分笔成交细节有限
  - 适合: 个人投资者首选

  国泰君安 QMT(中级专业)

  - 门槛: 资产 ¥50 万
  - 价格: 免费(开户即送)
  - 优点:
    - 行业标杆,机构主流
    - 速度极快
    - 支持算法交易(VWAP/TWAP)
    - 文档详细
  - 缺点:
    - 学习曲线陡
    - 部分高级功能需要资产 100 万
  - 适合: 严肃量化用户

  券商 PTrade(老牌)

  - 门槛: 资产 ¥50-100 万
  - 背景: 恒生电子开发,多券商支持
  - 特点: 老牌专业平台,机构最多用 PTrade
  - 缺点: 界面老旧,但稳

  3. 有没有更便宜的选择?

  门槛 < ¥20 万:几乎没有专业 API

  - 很多券商 APP 只支持手动下单
  - 部分支持"条件单"(预设触发条件),但功能有限

  变通方案:
  - 手动执行(每周一定时下单,30 分钟即可完成)
  - 券商 APP 网格交易(部分券商有,如东财、广发)
  - 同花顺 iFinD 量化(¥6000+/年,功能有限)

  4. 算法交易(资金 > 100 万)

  如果资金量大(冲击成本显著),需要算法拆单:



```txt
  ┌─────────┬──────────────────────┬────────────────────┐
  │  算法   │         用途         │      适合场景      │
```

  十一、常见的"购买决策"陷阱

  ❌ 陷阱 ①:工具买太多,时间不够

  很多人买了 3-5 个数据源,结果全部没用透。

  正解: 一个工具用熟,胜过五个工具浅尝。

  ❌ 陷阱 ②:迷信高价工具

  以为"花钱买 Wind 就能赚钱",忽略底层是策略而非数据。

  正解: ¥200/年的 Tushare Pro 完全够散户用。Wind 的边际价值在于极少数情境。

  ❌ 陷阱 ③:忽视免费工具

  很多人不知道 alphalens、vectorbt 都是免费的,专业级的开源工具。

  正解: 开源工具 80% 够用,付费只为最后 20% 的优势。

  ❌ 陷阱 ④:沉迷工具,不做策略

  花 3 个月对比工具,结果一行策略代码没写。

  正解: 工具是仆人,策略才是核心。能跑就行,先做出第一版。

  ❌ 陷阱 ⑤:买完工具就放弃

  很多人冲动消费(订阅 ¥3000 的平台),3 个月后再没登录。

  正解: 从免费版开始,有持续投入再升级。
