国内私募/公募的因子策略框架实战分析

  把视角从"个人策略"提升到"机构视角",能让你看到专业玩家如何处理你正在面对的同样问题。本节聚焦于国内真实存在的、可公开了解的量化机构框架,以及他们的处理方式。

  ▎ 核心问题: 当机构用 20 亿、200 亿资金管理类似逻辑时,他们做了什么不同的事?

  二、典型框架剖析:幻方量化(全市场选股)

  1. 策略基本架构(根据公开资料 + 业内披露)

```txt
  信号层(Alpha 工厂)
  ├── 量价因子(数百个) — 反转、动量、流动性、波动率类
  ├── 基本面因子(数十个) — 估值、成长、质量、分红
  ├── 另类因子 — 资金流、新闻情绪、行业轮动
  └── DL/ML 合成因子 — 神经网络从原始数据提取的非线性信号

  ⬇

  合成层(Factor Combination)
  ├── 因子加权(IC 加权 / 风险预算加权)
  ├── 多模型集成(Bagging / Boosting)
  └── 风格暴露中性化

  ⬇

  组合优化层(Portfolio Construction)
  ├── 目标:最大化预期收益 / 控制跟踪误差
  ├── 约束:单股 ≤ 1%、行业偏离 ≤ 2%、风格暴露 ≤ 0.5σ
  └── 换手率约束(年化 < 1500%)

  ⬇

  执行层(Execution)
  ├── 智能拆单(VWAP / TWAP / 自研算法)
  ├── T+1 约束下的等价 T+0 资金循环
  └── 滑点控制(目标 < 0.05%)
```

  2. 与你策略的核心差异

```txt
  ┌──────────────┬───────────────────────────┬─────────────────┐
  │     维度     │         幻方策略          │    你的策略     │
  ├──────────────┼───────────────────────────┼─────────────────┤
  │ 持仓数量     │ 1500-2500 只(几乎全市场)  │ 1-10 只         │
  ├──────────────┼───────────────────────────┼─────────────────┤
  │ 单股仓位     │ 0.05% - 0.5%              │ 1/3 ~ 2/3       │
  ├──────────────┼───────────────────────────┼─────────────────┤
  │ 信号数量     │ 数百到数千个因子          │ 4-5 个规则      │
  ├──────────────┼───────────────────────────┼─────────────────┤
  │ 再平衡频率   │ 每周 1-2 次(部分高频每日) │ 不定            │
  ├──────────────┼───────────────────────────┼─────────────────┤
  │ 风险控制     │ 多层硬约束                │ 几乎没有        │

  └──────────────┴───────────────────────────┴─────────────────┘
```

  3. 给你的关键启示

  启示 ①:"分散"是机构的第一防线
  - 幻方持仓 2000 只,最大单股 0.5%
  - 即使单股归零,对组合影响 < 0.5%
  - 你的策略持仓 1-10 只,单股可达 67%
  - → 风险敞口差距 100 倍以上

  启示 ②:不指望"信号准确",指望"信号多"
  - 单个因子的 IC(信息系数)通常只有 0.02-0.05
  - 含义:单个信号的预测能力只比掷硬币好一点点
  - 但 100 个信号叠加 → IC ≈ 0.15-0.20 → 稳定 alpha
  - → 机构靠"大数定律"赚钱,你靠"赌神预言"赚钱

  启示 ③:"换手"被严格管理
  - 幻方指增产品年换手 1000-1500%(看起来很高,但每只股票平均持有 10-15 个交易日)
  - 你的策略持有期 1-2 天 → 年换手 >20000%
  - → 你的"摩擦税"是机构的 15-20 倍

  三、典型框架剖析:九坤投资(工程派)

  1. 文化基因

  - 创始人姚齐聪(北大数学)、王琛(Citadel 系)
  - 极强的工程文化:开发自研交易系统、回测框架
  - 团队结构:因子研究员 + 算法工程师 + 交易员 = 1:1:0.5

  2. 策略框架特征

  研究流程:
  原始数据(每日 100GB+)
      → 特征工程(数千维度)
      → 信号挖掘(ML/DL)
      → 严格 OOS 验证(2/3 训练 + 1/3 测试 + 1/3 实盘)
      → 因子衰减监控(每周/每月)
      → 因子退役(若 IC 衰减 > 50%)

  3. 关键实务做法

  做法 ①:因子寿命管理
  - 任何因子都假设"会失效"
  - 定期监控 IC 衰减,及时退役失效因子
  - 每年新增 10-30 个因子,淘汰 20-30 个
  - 因子库始终保持"新陈代谢"

  做法 ②:严格的样本外验证
  - 训练期:60% 数据
  - 验证期:20% 数据(参数调优)
  - 测试期:20% 数据(完全 untouched)
  - 样本外 IC 显著低于样本内是正常的(50% 衰减是常态)

  做法 ③:多模型集成
  - 不依赖单一模型(LASSO、XGBoost、Neural Net 各跑一份)
  - 加权集成
  - 避免过拟合

  4. 给你的关键启示

  ▎ 你的策略几乎所有规则都是"主观经验设定"(为什么是 -3% 不是 -2%?为什么是 +2% 止盈不是 +3%?)。
  ▎
  ▎ 机构会做的事:
  ▎ 1. 参数全部经过 OOS 验证
  ▎ 2. 单一参数都有敏感性分析
  ▎ 3. 每个规则都有失效预案
  ▎
  ▎ 你应该问自己:"如果 -3% 改成 -4%,胜率/回报变化多大?如果 +2% 改成 +3% 呢?" — 如果你不知道答案,说明这些参数是主观选定的,这本身就是过拟合的高风险信号。

  四、典型框架剖析:明汯/灵均(量价 vs 量价+基本面)

  1. 明汯(纯量价学派)

  特征:
  - 几乎不用财务数据,只用价格、成交量、订单簿
  - 信号生命周期短(数天至数周)
  - 容量受限(资金过多会冲击市场)
  - AUM 一度突破 1000 亿后表现下滑(容量瓶颈)

  典型因子类型:
  - 短期反转(各种衍生形式)
  - 价量背离
  - 流动性冲击
  - 订单不平衡

  2. 灵均(量价 + 基本面融合)

  特征:
  - 创始人马志宇(原嘉实基金量化负责人)
  - 更重视基本面与量价的结合
  - 自称"基本面量化"派
  - 容量更大,长期更稳

  典型因子类型:
  - 价量因子(40%)
  - 基本面因子(30%)
  - 行业/风格轮动(20%)
  - 另类(10%)

  3. 对你策略的启示

  你的策略是"量价(-3% 跌幅) + 基本面(经营稳定) + 趋势"的混合 — 这个方向和灵均一致。

  但有三个关键差距:

  差距 ①:基本面信号的"动态性"
  - 灵均的基本面信号是实时更新的(每季度财报后重算)
  - 你的"经营稳定"是静态的、主观的
  - → 应改为"ROE_ttm > 12% AND 营收增速 > 5% AND 资产负债率 < 60% AND 应收账款 / 营收 < 30%"等可量化指标

  差距 ②:多因子组合,不是规则叠加
  - 灵均给每只股票打综合分数(0-100),取 top-N 持有
  - 你是用硬规则筛选(满足条件就买,不满足就不买)
  - → 硬规则的样本数极不稳定(有时 0 只,有时 50 只)
  - → 综合分数排序更稳健

  差距 ③:风险约束
  - 灵均的产品(指增)有明确跟踪误差约束(通常 3-5%)
  - 行业偏离、风格偏离都有上限
  - 你的策略没有任何风险约束

  五、典型框架剖析:衍复投资(中国 RenTech 风格)

  1. 神秘度最高的一家

  - 创始人高亢(美国 D.E. Shaw 出身)
  - 团队 不公开露面,采访极少
  - 业绩异常稳定(年化 30%+,几乎没有大回撤)

  2. 推测的策略框架

  ▎ 注:衍复信息极少,以下基于业内同行流传的非公开信息整理,仅供参考

  - 以中高频统计套利为主(持有期数小时至数日)
  - 大量自研基础设施(类 RenTech 模式)
  - 极强的执行算法(滑点接近 0)
  - 不公开募资,纯老客户

  3. 给你的关键启示

  最重要的一点:

  ▎ 顶级量化的核心竞争力不在因子,在执行。
  ▎ 同样的信号,滑点 0.05% vs 0.20% 的差异,长期年化收益差距 10-20%。

  你的策略中的"执行"考量:
  - 你说"-3% 时买入" — 但用什么价格成交?
    - 限价单?可能挂单不成交,错过反弹
    - 市价单?可能成交在更低位(对你有利)或更高位(对你不利)
    - 集合竞价?可能跳空到更低
  - 你说"+2% 时卖出" — 谁来盯盘?
    - 人工盯盘?情绪化,容易破规
    - 程序化?需要券商 API,你有吗?

  机构做法:
  - 用 VWAP/TWAP 算法减少冲击
  - 把单笔大单拆成 50-100 小单
  - 在集合竞价中用算法预估成交概率
  - → 滑点降到 5-10 个 bp(0.05-0.10%)

  3. 公募的"风格漂移"问题

  ▎ 一个有趣的现象:

  许多顶流公募基金经理(如张坤、刘彦春)长期重仓:
  - 茅台、五粮液
  - 招商银行、平安银行
  - 美的集团、格力电器

  这些股票的特征:
  - 大盘 ✅
  - 高 ROE ✅(平均 15-25%)
  - 低杠杆 ✅
  - 稳定增长 ✅

  这就是 Asness 定义的"质量 + 价值"!

  公募的隐含因子暴露:
  - 大盘 + 价值 + 质量(三因子高度叠加)
  - 但**披露形式是"基本面研究"**而非"因子投资"
  - → 专业投资者意识到他们的股票池就是因子选股,只是表达方式不同

  4. 给你的启示

  你的策略最接近的"公募版本"是:

  ▎ 价值股 + 短期回撤买入

  例子:
  - 茅台 2024 年底跌到 1300 元(52 周低点) → 价值投资者买入
  - 招商银行 2024 年中跌到 28 元 → 价值投资者买入
  - 美的集团 2022 年跌到 51 元 → 价值投资者买入

  公募基金经理的做法:
  - 不看 -3% 单日跌幅(他们认为太短期)
  - 看估值是否到达历史低位(PE/PB 分位数 < 30%)
  - 持有期 6-24 个月
  - 不用止损,用调仓(基本面恶化才卖)

  对比你的策略:
  - 你的"52 周均线下方"实际上是类似的价值锚
  - 但持有期 2 天 vs 12 个月 —时间尺度差距 200 倍
  - → 你用价值投资的入场逻辑,做了短线投机的执行
  - → 这是逻辑不自洽的核心问题

  八、可借鉴的"轻量化机构框架"

  如果你想把策略升级到准机构水平,但又不想搞那么复杂,这里是一个最小可行框架:

  第一层:量化的入场信号

  # 替代"经营稳定"的硬指标
```txt
  fundamental_score = (
      0.25 * z_score(ROE_ttm) +
      0.20 * z_score(revenue_growth_yoy) +
      0.15 * z_score(-debt_to_equity) +
      0.15 * z_score(-receivables_to_revenue) +
      0.15 * z_score(operating_cashflow / net_profit) +
      0.10 * z_score(-volatility_60d)
  )
```

  # 取 fundamental_score > 0.5 的池子(约 A 股 30%)

  第二层:多因子合成排序

  # 入场触发:从基本面池中,每日按以下分数排序

```txt
  entry_score = (
      -0.40 * daily_return +              # 跌得越多得分越高(短反转)
      -0.20 * (price / MA_252 - 1) +      # 估值锚(52 周均线下)
```

  十、终极图景对比

  散户思维(你当前):
  "我找到了一只好股票,跌了就买,涨了就卖,补仓拉低成本"
  ↓
  风险:单股、单笔、单次决策的命运决定一切
  ↓
  长期回报分布:左偏(偶尔大赚,经常被套,长期亏损)


  专业机构思维:
  "我有 200 个不太准的信号,合成后能找到 1500 只略有正期望的股票,
  分散持有,严格风控,通过大数定律和复利积累获利"
  ↓
  风险:分散到 1500 个独立小风险,任何单一事件影响极小
  ↓
  长期回报分布:中心紧,尾部薄(年化 15-25%,回撤 10-15%)


  差距的本质不是聪明程度,而是:
  - 信号的数量(几个 vs 几百)
  - 持仓的分散度(几只 vs 几千只)
  - 流程的纪律性(主观 vs 系统)
  - 失效的应对(死扛 vs 退役因子)
  - 执行的精度(手动 vs 算法)
